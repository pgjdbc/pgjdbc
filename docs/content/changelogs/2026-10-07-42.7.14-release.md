**Notable changes**

### Security
* fix: a `requireAuth` value that excludes every authentication method, such as `!password,!md5,!gss,!sspi,!scram-sha-256,!none`, now refuses every method, and a connection with such a value fails with SQLState `08004`. Releases 42.7.11 through 42.7.13 treated the value as if `requireAuth` were not set, and used any method the server asked for, even a cleartext password. A value without a method in it, such as `,`, now fails with SQLState `22023`.
See the [Security Advisory](https://github.com/pgjdbc/pgjdbc/security/advisories/GHSA-rhp9-mr79-r74h) for more detail.
The following [CVE-2026-107314](https://nvd.nist.gov/vuln/detail/CVE-2026-107314) has been issued.
* fix: when an application declares a length larger than the data it sends, for example a `ByteStreamWriter` whose `getLength()` is larger than what it writes, the driver pads the value with zeros. Releases 42.7.4 through 42.7.13 padded it with bytes of messages sent earlier on the same connection, so the stored value could contain SQL text and parameter values of earlier statements.
See the [Security Advisory](https://github.com/pgjdbc/pgjdbc/security/advisories/GHSA-f64h-wr5q-3qf3) for more detail.
The following [CVE-2026-107315](https://nvd.nist.gov/vuln/detail/CVE-2026-107315) has been issued.
